Architecture

The dashboard controls registered Android nodes. A real Android phone, emulator, or other Android runtime still provides the device itself. The API does not create Android VMs.

Connect Android node

The phone registers itself. Open the Node Agent on the Android device, enter the same API URL and NODE_TOKEN, then tap Register / Reconnect.

Node API: POST /api/node/register
Heartbeat: every 20 seconds
Offline: after 90 seconds without a heartbeat
